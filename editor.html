Sửa chữ, thay ảnh, xem thử và xuất file để cập nhật website.

Đây là bản nháp trên thiết bị của bạn. Editor không tự đăng thay đổi lên website. Chỉ người có quyền ghi GitHub mới có thể xuất bản bằng cách cập nhật file content.json.

Ảnh PNG/JPG/WebP/GIF tối đa 5 MB. Ảnh thay thế sẽ được nén và lưu trong file nội dung. Các lớp animation nên dùng PNG hoặc WebP nền trong suốt.

CÁCH XUẤT BẢN

  1. Chỉnh nội dung hoặc chọn ảnh mới, bấm Lưu bản nháp rồi Xem thử.
  2. Bấm Xuất content.json để tải file đã chỉnh.
  3. Mở repo GitHub của bạn ↗, chọn Add file → Upload files, upload file content.json vào thư mục gốc và bấm Commit changes.
  4. Netlify tự deploy. Tải lại website sau khi deploy hoàn tất.

Lần sau, mở lại Editor trên cùng trình duyệt để tiếp tục bản nháp, hoặc nhập file JSON đã xuất. Nên giữ một bản sao file nội dung trước khi sửa.

Muốn vẽ lại chi tiết bên trong ảnh: sửa bằng Photoshop/Figma rồi xuất PNG/WebP, sau đó thay ảnh ở đây. Với animation, thay từng lớp nhân vật để giữ chuyển động.
