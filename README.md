# Truong Thong Portfolio

Responsive static portfolio for Truong Thong (Tom Nguyen), Senior Graphic Designer.

## Files
- `index.html`: content, career timeline, project sections, and embedded WebP portraits.
- `style.css`: responsive styles and motion preferences.
- `app.js`: navigation, project filters, and project dialogs.
- `netlify.toml`: publish settings and response headers.

## Preview
Serve the repository with any static web server, for example `python3 -m http.server 8000`.

## Deploy
Netlify project: `truongthongportfolio`. Production branch: `main`. Publish directory: `.`. No build command or dependencies required.

## Content editing
Update profile and experience in `index.html`. Update project details in `app.js`. Project artwork is currently represented by explicitly labeled overview graphics; replace these with original portfolio images before using the site as a full case-study collection.

The site includes a custom AI-generated voxel avatar based on an owner-supplied reference photo, with the owner's permission. Personal contact is provided through an email link.
